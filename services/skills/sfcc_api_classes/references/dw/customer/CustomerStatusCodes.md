# dw.customer.CustomerStatusCodes

## Overview
Constants representing status codes for customer-related operations.

## Description
Provides string constants used with `Status` objects to indicate success or specific failure conditions when operating on customers or related objects.

```ts
declare class CustomerStatusCodes  {
    /**
     * Example constant: an address referenced by a product list.
     */
    static CUSTOMER_ADDRESS_REFERENCED_BY_PRODUCT_LIST: 'CUSTOMER_ADDRESS_REFERENCED_BY_PRODUCT_LIST'
}
```
