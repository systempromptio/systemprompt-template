# dw.campaign.FreeDiscount

## Overview
Represents a free discount in a discount plan (for example, "Free shipping on all orders $25 or more").

## Description
Represents a free discount type in the discount plan. This class has no public constructor and is typically obtained from promotion/discount APIs rather than created directly.

```ts
declare class FreeDiscount extends dw.campaign.Discount {
    // No constructor: instances are provided by the platform
}
```
