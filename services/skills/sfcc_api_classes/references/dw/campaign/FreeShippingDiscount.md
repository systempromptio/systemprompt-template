# dw.campaign.FreeShippingDiscount

## Overview
Represents a free-shipping discount in a discount plan (for example, "Free shipping on all iPods").

## Description
Represents a free shipping discount type. This class has no public constructor and is obtained from promotion/discount APIs rather than created directly.

```ts
declare class FreeShippingDiscount extends dw.campaign.Discount {
    // No constructor: instances are provided by the platform
}
```
