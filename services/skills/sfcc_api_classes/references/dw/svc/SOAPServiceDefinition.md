# dw.svc.SOAPServiceDefinition

## Overview
SOAP WebService definition. Deprecated as of version 19.10; configure SOAPService directly via LocalServiceRegistry.

## Description
Represents a SOAP WebService definition for configuring SOAP services. Part of the deprecated ServiceRegistry system. Use LocalServiceRegistry which allows direct configuration on the SOAPService instead.

```ts
declare class SOAPServiceDefinition extends ServiceDefinition {
}
```
