# dw.svc.HTTPFormServiceDefinition

## Overview
HTTP Form POST service definition (deprecated).

## Description
Represents an HTTP Form POST Service Definition. No longer available as of version 19.10. This class is only used with the deprecated ServiceRegistry. Use the LocalServiceRegistry instead, which allows configuration on the HTTPFormService directly.
