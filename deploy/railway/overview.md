# Deploy and Host systemprompt.io with Railway

systemprompt.io is a self-hosted AI governance gateway. Run an AI gateway, administrator interface, MCP server orchestration, and an audit database in your own Railway project. Connect supported AI providers and apply authentication, authorization, secret scanning, and rate limits while retaining request, identity, usage, and cost records in PostgreSQL.

## About Hosting systemprompt.io

This template deploys the published systemprompt container and PostgreSQL. Set an administrator email address you control and at least one provider API key before deploying. Database credentials are generated by Railway, and the gateway connects through private networking. First boot initializes the profile, applies migrations, and prepares web assets; allow up to 15 minutes for readiness. Application identity and uploads live on a persistent volume, and PostgreSQL has its own volume. HTTPS protects browser and API access. Public registration is disabled; use the service shell to issue the administrator's one-time passkey enrollment link. Redeploy explicitly to consume a newer image.

## Common Use Cases

- Govern requests from AI coding clients through a shared gateway.
- Authenticate and authorize access to MCP tools.
- Investigate requests using identity, trace, usage, and cost records.
- Evaluate governance policies with data stored in your own database.

## Dependencies for systemprompt.io Hosting

- PostgreSQL, included with private networking and persistent storage.
- An Anthropic, OpenAI, or Google Gemini account and its API key.
- Railway service and volume capacity; hosting and provider usage are billed separately.

### Implementation Details

The public endpoint is the gateway on port 8080. PostgreSQL is private. Readiness is checked at `/api/v1/health`. Mount gateway state at `/app/data`; the Railway PostgreSQL image uses `PGDATA=/var/lib/postgresql/data/pgdata` under its `/var/lib/postgresql/data` volume. Do not substitute an upstream PostgreSQL image without reviewing its storage layout.

In the gateway service shell, enroll the bootstrap administrator:

```sh
systemprompt admin users webauthn generate-setup-token --email "$ADMIN_EMAIL"
```

Open the returned link privately to enroll a passkey. Do not publish the link or token.

### Why Deploy systemprompt.io on Railway?

Railway provisions the gateway, private database connection, HTTPS endpoint, and persistent volumes together. Operators can inspect logs and redeploy a published image from one project while retaining ownership of their configuration and audit data.
